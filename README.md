# notion-covers

Gradient cover images (3840x1280 JPEG) for Notion pages.

Colors come from the 497 palettes listed on R CHARTS (https://r-charts.com/color-palettes/), which collects palettes from R packages via paletteer (ggthemes, grDevices, ggsci, RColorBrewer, viridis, wesanderson and others). File names start with the R CHARTS order number followed by the palette name.
